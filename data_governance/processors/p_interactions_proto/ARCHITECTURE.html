P-interactions prototype — Architecture

Derives agentic entities and their interactions from OTel spans, via a single base graph progressively colored by scope semantics. See docs/adr/0025-p-interactions-graph-algorithm.md. Throwaway logic prototype.

entry points  ·  cli.py  /  POST /proto/process/<trace_id>

│spans▼
extractor.py orchestrator
Runs the pipeline in order; snapshots the base graph (after Step 1) and the colored graph (after Step 2.d); derives ProtoEntity / ProtoInteraction / ProtoPayload rows. Interaction timing follows the anchor span.
  • S1 → S2.a/b → S2.c → S2.d → S3.a → S3.b
builder.py the algorithm
  • 1build_base_graph — node/span, White traceparent edges
  • 2.acolor_transport — Teal (httpx/starlette/asgi)
  • 2.bcolor_agentic — Blue + Blue chain edges
  • 2.cduplicate_combined_nodes (case 1)
  • infer_tool_calls_from_attributes (case 3)
  • synthesize_missing_peers (one-sided stub)
  • infer_agent_from_bare_leaf_llms (case 4)
  • 2.dmerge_identical_interactions
  • 3.a/3.bbuild_entity_graph — drop Teal, group components (3.a nodes) + one interaction per Teal chain (3.b edges)
  • 3.acombine_identical_entities — semantic combine of same-entity groups
│ operates on ▼
graph.py data structures
  • BaseGraph: Node, Edge — color, is_inferred, order, replaces
  • EntityGraph: EntityNode, EntityEdge — fuse output
Inferred identity is a boolean field, never label parsing.
adapters.py isolation layer
The only place raw OTel attribute keys are read. One SpanAdapter per (scope, framework) → typed SpanFacts.
  • openai_agents · claude_agent_sdk · anthropic
  • google_adk · strands_agents · mcp
  • * — generic openinference fallback
_VersionedSchema tables = schema drift (declarative). Span-name parsing = behaviour drift (in code). is_transport_scope · dispatch.
▲ SpanFacts  ·  facade ▼
classifiers.py thin facade
SpanFacts → AgenticClassification. A shim the builder consumes — edit adapters.py, not this.

Dependency direction: cli → extractor → { builder → graph, adapters }; classifiers is a facade over adapters; adapters is the sole boundary against raw OTel vocabulary.
